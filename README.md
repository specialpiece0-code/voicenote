# 보이스노트 (VoiceNote)

서버·계정·설치 없이 브라우저에서 바로 동작하는 로컬 음성 노트 앱입니다.
녹음 → 실시간 음성인식 → AI 정리(요약·주제·할 일·키워드) → 검색 → 내보내기까지
네이버 클로바노트의 주요 기능을 순수 정적 웹앱(HTML/CSS/Vanilla JS)으로 구현했습니다.
모든 데이터는 이 브라우저의 IndexedDB에만 저장됩니다.

## 실행법

1. **`시작하기.cmd` 더블클릭** → 로컬 서버가 뜨고 기본 브라우저로 `http://localhost:8788` 이 열립니다.
   - 포트가 사용 중이면 자동으로 8789, 8790… 으로 옮겨서 실행합니다(브라우저도 그 주소로 열림).
   - 수동 실행: `powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1 -Port 8788 -OpenBrowser`
2. **Chrome 또는 Edge 권장.** 첫 녹음 시 마이크 권한을 허용해 주세요.
3. 처음이라면 **설정 → 데모 노트 생성** 으로 주요 기능을 바로 볼 수 있습니다.

### 왜 localhost 서버가 필요한가요?
마이크(getUserMedia)와 음성인식(SpeechRecognition)은 보안 컨텍스트(HTTPS 또는 localhost)에서만
동작합니다. `file://` 로 열면 녹음이 불가능하므로 간단한 로컬 서버(`server.ps1`)를 동봉했습니다.
서버는 파일을 제공할 뿐, 어떤 데이터도 외부로 보내지 않습니다.

## 온라인 배포 (GitHub + Render)

이 저장소는 빌드 과정이 없는 정적 사이트라 Render 정적 호스팅에 바로 올릴 수 있습니다.

1. GitHub에 `voicenote` 저장소를 푸시합니다 (이 저장소).
2. [Render 대시보드](https://dashboard.render.com) → **New** → **Blueprint** 를 선택하고 `voicenote` 저장소를 연결하면
   동봉된 `render.yaml` 설정(정적 사이트, 게시 디렉터리 `.`)대로 자동 배포됩니다.
   - Blueprint 대신 **New → Static Site** 로 만들어도 됩니다. 이때 Build Command는 비워 두고
     Publish directory에 `.` 을 입력하세요.
3. 이후 `main` 브랜치에 푸시할 때마다 자동으로 재배포됩니다.

배포 시 알아둘 점:

- Render 주소는 **HTTPS**라서 마이크(getUserMedia)와 실시간 음성인식(SpeechRecognition)이
  로컬 서버(`시작하기.cmd`) 없이 브라우저에서 바로 동작합니다.
- **데이터는 서버에 저장되지 않습니다.** 노트·오디오·설정은 접속한 각 브라우저의 IndexedDB에만
  저장되므로, 같은 주소로 접속해도 기기(브라우저)마다 데이터가 다르고 기기 간 공유되지 않습니다.
  다른 기기로 옮기려면 설정 → 전체 백업 → 새 기기에서 복원을 사용하세요.

| 실시간 음성인식 자막 | SpeechRecognition (중간결과 회색 + 확정 세그먼트 누적, 자동 재시작) |
| 다국어 인식 | 한국어/영어/일본어/중국어 선택 |

| 하이라이트 | 세그먼트 형광 강조 + 모아보기 |

| AI에게 질문 (Ask AI) | AI 요약 탭 하단 입력창 — 전사 전체(+메모)를 컨텍스트로 Gemini에 질문. 질문·답변 이력은 노트에 저장(최근 20개) |
| 통화/외부 파일 불러오기 | mp3/m4a/aac/wav/webm/ogg 업로드·드래그&드롭, 파일명으로 통화/회의 자동 태그 + **"가져온 음원" 폴더 자동 배정**(없으면 자동 생성) |

| 검색 | 전역 검색(제목·본문·메모, 미리보기 하이라이트, 위치 점프) + 노트 내 검색·한 번에 바꾸기 |

| 휴지통 | 30일 보관 후 자동 영구삭제, 복원/개별 영구삭제/비우기 |

## 회의록 Google Drive 자동 저장

녹음 종료·업로드 변환 직후 회의록(DOC/TXT)을 자동으로 저장합니다.
파일명은 `YYYY-MM-DD_HHmm_<대화주제>.doc` — 주제는 Gemini 키가 있으면 AI가 15자 이내로 생성하고,
없거나 실패하면 로컬 키워드 상위 2개로 만듭니다. 노트 제목도 같은 주제로 갱신됩니다.
설정에서 자동 저장 온/오프, DOC/TXT 형식, "오디오(webm)도 함께 저장", 마지막 저장 결과를 관리하고,
노트 상세의 ☁ 버튼으로 언제든 수동 재저장(같은 파일명 유지)할 수 있습니다.

저장 경로는 설정에서 **하나만** 고릅니다: **PC 폴더 / Drive API(권장) / Apps Script 웹훅 / 사용 안 함**.

### ⓪ Drive API (권장 — PC·Android 공용, 같은 이름은 덮어쓰기)

Google 계정으로 한 번 로그인해 두면 PC와 Android 어디서든 별도 설정 없이 내 Drive의 `회의록`
폴더에 바로 업로드됩니다. 같은 폴더에 같은 파일명이 있으면 **덮어써서** 사본이 쌓이지 않고,
업로드 후에는 노트 상세에 **"Drive에서 열기"** 링크가 표시됩니다. 웹훅 경로와 달리 **용량 제한이 없어**
오디오 동반 저장도 그대로 올라갑니다.

#### Google Cloud 콘솔 설정 (신형 "Google 인증 플랫폼" UI 기준)

1. [console.cloud.google.com](https://console.cloud.google.com) → **새 프로젝트** 생성.
2. **API 및 서비스 → 라이브러리** → **Google Drive API** 와 **Google Calendar API** 를 각각 **사용 설정**.
3. **Google 인증 플랫폼**(구 OAuth 동의 화면) → **브랜딩**에서 앱 이름과 사용자 지원 이메일을 입력.
4. **대상** 탭 → **"외부로 설정"** 버튼으로 사용자 유형을 외부로 지정 →
   **테스트 사용자**에 본인 이메일(`special.piece0@gmail.com`)을 추가.
5. **클라이언트** 탭 → **클라이언트 만들기** → 애플리케이션 유형 **웹 애플리케이션** →
   **승인된 JavaScript 원본**에 아래 **두 개를 모두** 추가 (승인된 리디렉션 URI는 **비워 둡니다**):
   - `https://voicenote-l0ox.onrender.com`
   - `http://localhost:8788`
6. 발급된 **클라이언트 ID**를 복사해 보이스노트 **설정 → Google 계정 → 클라이언트 ID**에 붙여넣고 저장 →
   **Google 로그인** 버튼을 누릅니다.

> 팁: 로그인 동의 화면에 표시되는 앱 이름은 **브랜딩**에서 언제든 변경할 수 있습니다
> (현재 사용자 프로젝트는 'slack'으로 표시됨).

테스트 모드(게시 안 함) 상태라 로그인할 때 **"Google에서 확인하지 않은 앱"** 경고가 나옵니다.
본인 계정으로 본인이 만든 앱에 접속하는 것이므로 **고급 → (앱 이름)(으)로 이동**을 눌러 계속 진행하면 됩니다.
요청 범위는 `drive`(전체) 와 `calendar.readonly` 입니다 — **이미 만들어 둔 `회의록` 폴더를 찾아 그 안에 쓰기 위해**
좁은 `drive.file`(앱이 만든 파일만) 대신 `drive`를 사용합니다.

### ① PC 폴더 저장 (PC Chrome — Google Drive for Desktop)

1. 설정 → Google Drive 자동 저장 → **PC 저장 폴더 선택** → `G:\내 드라이브\회의록` 선택.
2. 폴더 핸들은 브라우저(IndexedDB)에 저장됩니다. 브라우저 재시작 후 권한이 풀리면
   상단 배너의 **재승인** 버튼(사용자 클릭 필요)으로 다시 허용하세요.
3. 같은 파일명이 이미 있으면 ` (2)` 를 붙여 저장합니다. 수동 재저장은 기존 파일을 덮어씁니다.
4. Android Chrome은 이 API를 지원하지 않아 버튼이 숨겨집니다 — 아래 웹훅을 사용하세요.

### ② Apps Script 웹훅 (Android·클라우드 직접 업로드)

1. [script.google.com](https://script.google.com) → 새 프로젝트 → 아래 코드 붙여넣기
   (`SECRET`을 원하는 문자열로 변경):

```javascript
const SECRET = 'CHANGE_ME'; // 원하는 문자열로 변경
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  if (d.token !== SECRET) return out_({ok:false, error:'bad token'});
  const folder = folder_('회의록');
  const blob = Utilities.newBlob(Utilities.base64Decode(d.dataBase64), d.mimeType || 'application/octet-stream', d.filename);
  const f = folder.createFile(blob);
  return out_({ok:true, id:f.getId(), url:f.getUrl()});
}
function folder_(name){ const it = DriveApp.getFoldersByName(name); return it.hasNext() ? it.next() : DriveApp.createFolder(name); }
function out_(o){ return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
```

2. 배포 → **새 배포** → 유형: **웹 앱** → 실행: **나** → 액세스: **링크가 있는 모든 사용자** → 배포 → **URL 복사**.
3. 보이스노트 설정에 URL과 SECRET(비밀 토큰)을 입력·저장.
4. 회의록은 내 Drive의 `회의록` 폴더에 저장됩니다. 전송은 커스텀 헤더 없는 text/plain POST(단순 요청)라
   CORS preflight가 없습니다. 실패하면 재시도 큐(IndexedDB)에 보관했다가 앱 시작 시 다시 보내고,
   18MB 초과 페이로드는 건너뛰고 알립니다. 웹훅 경로의 재저장은 Drive에 새 파일로 생성됩니다(덮어쓰기 없음).

## Google Calendar 연동

위 Drive API와 같은 로그인(스코프 `calendar.readonly`)을 그대로 사용합니다.

- **녹음 시작 화면** — 현재시각 **±30분** 일정이 있으면 상단에
  `📅 <일정 제목> · 참석자 N명 — 이 일정으로 기록` 칩이 뜹니다. 누르면 노트 제목이 일정 제목으로,
  참석자 탭이 일정 참석자 이름(`displayName`, 없으면 이메일 로컬파트)으로 채워집니다.
- **노트 상세 📅 버튼** — 최근 7일 ~ 앞으로 7일 일정 목록에서 하나를 골라 연결합니다.
  제목 적용·참석자 적용을 각각 체크박스로 선택할 수 있습니다.
- 연결한 일정은 노트에 `{id, title, start}`로 저장되고, **Drive 파일명의 주제로 가장 먼저 사용**됩니다
  (Gemini 생성 주제보다 우선, 15자 초과 시 자름).
- 로그인하지 않았거나 권한이 없으면 칩·버튼이 **조용히 숨겨집니다**(에러 배너 없음).

## 백그라운드 녹음·크래시 복구

- 경과시간·세그먼트 타임스탬프는 `Date.now()` 절대시각 차(일시정지 차감)로 계산 — 탭이 백그라운드로
  가도 시간이 밀리지 않습니다. 화면 타이머·파형은 UI 전용입니다.
- 녹음 중 1초 단위 청크와 메타(세그먼트·메모·북마크·경과시간)를 5초마다 IndexedDB에 저장합니다.
  브라우저가 죽어도 다음 실행 시 **"지난 녹음 복구"** 배너로 노트를 되살릴 수 있습니다.
- 음성인식은 끊기면 자동 재시작하며, 백그라운드에서 60초 이상 결과가 없었으면 복귀 시 경고 배너를
  띄웁니다(이 경우 노트의 🎤 "다시 변환(자동)"으로 전체 재전사 가능).
- **수음 보강** — 마이크는 에코 제거·노이즈 억제·자동 게인을 켠 상태로 열고, 그 위에 WebAudio
  컴프레서(+게인) 체인을 거친 스트림을 녹음해 작은 목소리를 키웁니다. 파형·레벨 표시도 처리된
  신호 기준입니다.
- 녹음 중 탭 제목이 `● mm:ss 녹음 중`으로 갱신되고, 화면 켜짐 유지(Wake Lock) 옵션과
  녹음 중 새로고침/닫기 확인 대화상자를 제공합니다.

## 자동 텍스트 변환 (백그라운드)

녹음 종료·파일 불러오기 직후 **방식을 묻지 않고 자동으로** 텍스트 변환을 시작합니다.
엔진은 저장된 키에 따라 자동 선택됩니다: **Deepgram**(화자분리 포함, 우선) → **AssemblyAI**(예비)
→ **Gemini**(`gemini-3.5-flash` 고정 — 3.6 오디오 입력 호환 검증 전, 화자 추정) 순으로 시도하고, 키가 하나도 없으면
"설정에서 Deepgram 또는 Gemini 키를 등록하세요" 안내가 노트에 남습니다.

- **변환은 백그라운드로 진행됩니다** — 진행 모달이 없고, 변환 중에도 앱 안에서 자유롭게
  이동할 수 있습니다. 노트의 음성 기록 탭에 "⏳ 자동 텍스트 변환 중" 상태가, 리스트 카드에는
  "변환 중…" 표시가 뜨고, 완료되면 토스트로 알립니다.
- **탭을 닫아도 됩니다** — 진행 중 요청은 끊기지만 노트에 남은 pending 플래그로
  다음 실행 때 자동으로 이어서 변환합니다(닫기 전 확인 대화상자 1회).
- 실패하면 노트에 원인과 **[다시 시도]** 버튼이 표시됩니다.
- 노트 상세의 🎤 버튼은 "다시 변환(자동)" — 이미 세그먼트가 있는 노트만 대체 확인을 받습니다.
- Drive 자동 저장은 **변환이 끝난 뒤 1회** 실행됩니다(변환 실패 시에도 오디오·메모는 저장).
- Gemini 경로는 오디오 18MB 이하 제한이 있고, 긴 녹음의 잘린 응답(MAX_TOKENS)은 관용 파서로
  부분 결과를 살립니다. 5xx/429/타임아웃/파싱 실패는 1회 자동 재시도.

## 제한사항

- **자동 화자 분리는 외부 API 필요** — 브라우저에는 화자분리 API가 없습니다. Deepgram 또는 AssemblyAI
  키를 설정에 입력하면 업로드 변환·오디오 전체 재변환에서 자동 화자분리를 쓸 수 있고, 키가 없으면
  녹음 중 참석자 탭을 수동으로 전환합니다.
- **SpeechRecognition은 온라인 필요** — 브라우저 내장 음성인식은 브라우저 벤더의 서버를 사용하므로 인터넷 연결이 필요하고, Firefox에서는 지원되지 않습니다(배너로 안내, 녹음만 진행).
- **실시간 자막은 PC 전용** — 모바일(Android/iOS)에서는 음성인식이 녹음과 마이크를 공유하지 못해 실시간 자막 없이 녹음만 진행하고, 녹음을 마치면 자동으로 텍스트 변환이 시작됩니다.
- **다른 앱 소리 차단은 에코 제거가 최대치** — echoCancellation은 같은 기기가 재생 중인 다른 앱 오디오를 마이크 신호에서 상쇄하지만, 다른 앱의 재생 자체를 음소거하는 것(오디오 포커스 독점)은 웹 API로 불가능하며 네이티브 앱(APK) 영역입니다.
- **링크 공유 없음** — 서버가 없으므로 공유용 단일 HTML 파일 내보내기로 대체합니다(비밀번호 암호화 지원).
- **데이터는 브라우저에 저장** — 브라우저의 사이트 데이터를 삭제하면 노트도 사라집니다. 주기적으로 백업하세요.
- Gemini 고급 모드는 브라우저에서 직접 호출하므로 API 키가 브라우저(IndexedDB)에 저장됩니다. 공용 PC에서는 사용하지 마세요.

## FAQ

**Q. 녹음 버튼을 눌러도 아무 일도 없어요.**
A. 주소가 `http://localhost:…` 인지 확인하세요. `file://`로 열면 마이크를 쓸 수 없습니다.
브라우저 주소창의 마이크 권한이 차단되어 있지 않은지도 확인하세요.

**Q. 자막(음성인식)이 안 나와요.**
A. Chrome/Edge인지, 인터넷이 연결돼 있는지 확인하세요. Firefox는 음성인식을 지원하지 않습니다.
무음이 길면 인식이 잠깐 끊겼다 자동으로 재시작됩니다.

**Q. 업로드한 파일이 자동으로 텍스트가 되지 않아요.**
A. 설정에 Deepgram 또는 Gemini API 키가 저장돼 있어야 자동 변환됩니다. 키가 있으면 업로드 직후
백그라운드로 변환이 시작되고, 실패 시 노트의 [다시 시도] 버튼으로 재시도할 수 있습니다.
음성 기록 탭의 "구간 추가"로 직접 입력할 수도 있습니다.

**Q. 다른 컴퓨터로 옮기려면?**
A. 설정 → 전체 백업(오디오 포함 체크) → 새 기기에서 설정 → 복원.
백업에는 API 키가 포함되지 않으므로 기기 이전 후 키는 다시 입력하세요.

**Q. AI 요약 품질을 높이고 싶어요.**
A. 설정에 Gemini API 키를 입력하면 고급 모드(기본 `gemini-3.6-flash`)로 동작합니다. 키는 Google AI Studio(aistudio.google.com/apikey)에서 무료로 발급받을 수 있고 이 브라우저에만 저장됩니다. 키가 없거나 실패하면 오프라인 추출 요약으로 자동 폴백합니다.
